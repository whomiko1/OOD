# 自動知識庫系統設定紀錄

## 系統概覽

一套讓知識庫自動運作的系統：文章 highlight 自動同步、手機隨手捕獲、每天早上自動生成 AI 簡報。

```
讀文章 highlight → Readwise → Obsidian Notes/
手機傳訊息 → Telegram Bot → Obsidian Inbox/
每天 06:00 → Claude 分析 → Obsidian Inbox/daily-brief
```

---

## 元件清單

### 1. Readwise × Obsidian 插件
- **用途**：文章 highlight 自動同步到 Notes/
- **插件位置**：`.obsidian/plugins/readwise-official/`
- **設定**：Base folder 設為 `Notes`
- **操作**：讀文章時用滑鼠 highlight，其他全自動

### 2. Telegram Bot（快速捕獲）
- **用途**：手機隨手記想法，自動存入 Inbox/
- **腳本位置**：`C:\Users\User\telegram-obsidian.js`
- **開機自啟**：`C:\Users\User\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\telegram-obsidian.vbs`
- **安全機制**：Chat ID 白名單，只接受本人訊息；`/` 開頭指令自動過濾

### 3. 每日簡報（Claude 自動分析）
- **用途**：每天早上 Claude 讀近期筆記，輸出連結、模式、問題
- **腳本位置**：`C:\Users\User\daily-brief.js`
- **執行時間**：每天 06:00（Windows 工作排程器，任務名稱：`Obsidian-DailyBrief`）
- **輸出位置**：`Inbox/YYYY-MM-DD-daily-brief.md`
- **使用帳號**：Claude Max（不需要另外申請 API Key）

## 維護與疑難排解

### Telegram Bot 停止運作
1. 開啟命令提示字元
2. 執行：`node C:\Users\User\telegram-obsidian.js`
3. 或重新登入 Windows（開機自啟會重跑）

### 每日簡報沒有生成
1. 確認電腦在 06:00 有開機
2. 手動執行：`node C:\Users\User\daily-brief.js`

### 更換 Telegram Bot Token
1. 到 @BotFather 傳 `/revoke` 取得新 Token
2. 編輯 `C:\Users\User\telegram-obsidian.js` 第 5 行的 TOKEN 值
3. 重新啟動腳本

### Readwise 沒有同步
1. 開 Obsidian → 設定 → Readwise Official
2. 點 **Initiate Sync** 手動觸發
